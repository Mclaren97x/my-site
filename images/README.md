# Photos

Drop your photos in this folder with these exact names and they appear on the site automatically. Until a photo is added, a dark placeholder shows in its spot.

| File | Where it shows | Best shape |
|---|---|---|
| `hero.jpg` | Full-screen background at the top | Wide (landscape), at least 2400px across |
| `gallery-1.jpg` | Gallery, wide tile (Rolling) | Landscape |
| `gallery-2.jpg` | Gallery (Details) | Any |
| `gallery-3.jpg` | Gallery, tall tile (Static) | Portrait |
| `gallery-4.jpg` | Gallery (Events) | Any |
| `gallery-5.jpg` | Gallery (Details) | Any |
| `gallery-6.jpg` | Gallery, wide tile (Static) | Landscape |
| `gallery-7.jpg` | Gallery (Rolling) | Any |
| `gallery-8.jpg` | Gallery (Events) | Any |
| `gallery-9.jpg` | Gallery (Details) | Any |
| `me.jpg` | About section photo (already added) | Portrait |
| `logo-small.png` | Header and footer logo (already added) | White on transparent |

Export at around 2000px on the long edge and 80% JPEG quality so the site stays fast.
To change a photo's caption or category, edit its `<figure>` line in `index.html`.
